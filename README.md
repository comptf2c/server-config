# CompTF2C / xinayder's den server configs
This is a repository containing base server config files and plugins that should be installed on the server.

## Installation
1. Download and install MetaMod and Sourcemod
  - Currently supported versions: MM 2.0.0-dev+1402, SM 1.13.0.7435

2. Download `sm-tf2.games.txt` from TF2C Discord and save it to `addons/sourcemod/gamedata/custom`

3. Download `game.tf2.ext.2.tf2.so` from TF2C Discord and save it to `addons/sourcemod/extensions/x64`

4. Download and install the plugins mentioned below

5. Install the config files from this repo


## Plugins

- [F2 Medicstats](https://github.com/F2/F2s-sourcemod-plugins/tree/master/medicstats)
